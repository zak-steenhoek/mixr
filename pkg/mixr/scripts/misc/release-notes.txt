**Launch instructions**

- **First-time users:** upload the compatible [upstream deej Arduino sketch](https://github.com/omriharel/deej/blob/master/arduino/deej-5-sliders-vanilla/deej-5-sliders-vanilla.ino) to the board, then follow the [mixr setup instructions](https://github.com/zak-steenhoek/mixr#build-procedure)
- Download both `config.yaml` and `mixr.exe` (below, under _Assets_) and place them in the same directory
- Verify that your config has the correct COM port for your Arduino board
- Launch `mixr.exe`. You can always edit the config while mixr is running

**_Linux users:_** for the time being, please build from source. You'll need `libgtk-3-dev`, `libappindicator3-dev` and `libwebkit2gtk-4.0-dev` for system tray support. If there's demand for precompiled release binaries, please [let us know!](https://discord.gg/nf88NJu)

> _Tip:_ If `mixr.exe` seems to crash or doesn't start, attach the `logs\mixr-latest-run.log` file when reporting the issue.

> _Tip:_ `mixr-debug.exe` is a version with a console window that displays additional logs.

More detailed instructions and documentation are in the [mixr repository](https://github.com/zak-steenhoek/mixr).

Enjoy!
